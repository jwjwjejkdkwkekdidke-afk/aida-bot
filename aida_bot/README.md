# Бот «Айда! 1 Сезон»

Telegram-бот: превью 8 серий, оплата сезона 499 ₽ переводом на карту ЮMoney с подтверждением админом, после оплаты — доступ к видео.

## Установка

```bash
git clone <ваш-репозиторий>
cd aida_bot
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # и заполните значения
python main.py
```

## Настройка

1. Создайте бота в [@BotFather](https://t.me/BotFather), токен → `BOT_TOKEN`.
2. Свой Telegram ID (через [@userinfobot](https://t.me/userinfobot)) → `ADMIN_IDS` — сюда приходят заявки на оплату.
3. Номер карты для оплаты — в `config.py` (`CARD_NUMBER`) или переменной окружения `CARD_NUMBER`.

## Как добавить видео серий

1. Запустите бота и отправьте ему видео серии со своего админ-аккаунта.
2. Бот ответит `file_id`.
3. Вставьте его в `episodes.json` в поле `video` нужной серии.

## Как проходит оплата

1. Пользователь нажимает «Купить» и видит номер карты.
2. Переводит деньги и жмёт «✅ Я оплатил», присылает скриншот.
3. Админ получает скриншот с кнопками «Подтвердить» / «Отклонить».
4. После подтверждения пользователю открывается доступ ко всем сериям.

## Команды админа

- `/stats` — статистика и выручка
- `/grant USER_ID` — выдать доступ вручную

## Структура

```
main.py        — запуск
config.py      — настройки
handlers.py    — логика бота
keyboards.py   — кнопки
db.py          — SQLite (пользователи, покупки)
episodes.py    — загрузка серий
episodes.json  — список серий и видео
images/        — превью серий (ep1.jpg … ep8.jpg)
```
